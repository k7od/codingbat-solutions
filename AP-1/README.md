# AP-1:


## Purpose:

Designed to prepare students for the AP Computer Science exam by providing practice with array and loop manipulation. The problems emphasize array traversal, value filtering, and frequency-based logic, reflecting common AP-level questions.


## Key Concepts:

- Iteration over arrays
- Counting values and conditions
- Subarray and sequence logic
- Boolean flag usage
- Comparing and filtering elements
- Logical condition chaining
- 

## Problem Styles:

- Count elements based on conditions
- Build subarrays based on rules
- Find matching or non-matching patterns
- Detect numeric relationships in arrays
- Use loop control to manage multiple conditions


## Difficulty:

Medium
