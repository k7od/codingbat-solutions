
CodingBat Solutions:

This repository contains Java solutions for problems from CodingBat, a platform that helps improve programming skills through short practice exercises. The problems focus on basic programming concepts, logic, string manipulation, functional operations, and map usage.

Functional-1:

This section introduces functional programming concepts applied to lists (arrays):

Applying functions like map to transform each element

Filtering lists based on conditions

Using loops or recursion to process list elements

Problems often ask you to return a new list with modified elements, such as adding 1 to each number or converting strings to lowercase.

Skills developed: Working with collections, higher-order functions, functional transformations.
