CodingBat Solutions
This repository contains Java solutions for problems from CodingBat, a platform that helps improve programming skills through short practice exercises. The problems focus on basic programming concepts, logic, string manipulation, functional operations, and map usage.

String-1:

In this section, you practice manipulating strings. Problems often involve:

Extracting substrings or characters

Concatenation of strings

Removing or replacing characters

Checking prefixes, suffixes, or substring presence

Working with string length and indexing

Typical problems include removing specific characters from a string, building new strings from parts of the input, or counting occurrences of a substring.
