# CodingBat Solutions:

This repository contains Java solutions for problems from CodingBat, a platform that helps improve programming skills through short practice exercises. The problems focus on basic programming concepts, logic, string manipulation, functional operations, and map usage.

# Map-1:

The Map-1 section focuses on problems involving maps (also known as dictionaries or hash tables):

Adding, removing, and modifying key-value pairs

Checking presence of keys

Counting or accumulating values

Updating map entries based on given rules

Typical tasks include counting occurrences of strings, manipulating inventory maps, or merging maps with rules.
